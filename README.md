# AI Personal Portfolio Website Builder

## Project overview
This is a responsive, browser-based portfolio builder for a college VAC project. A user enters personal details, skills, education, projects and contact information. The page instantly creates a live portfolio preview.

## Features
- Personal information form
- Live portfolio preview
- Skills and project sections
- Three visual themes
- Local “AI-style About” text generator (template-based demo)
- Download portfolio as an HTML file
- Responsive layout for mobile and desktop

## Tools used
- HTML5: page structure
- CSS3: layout, styling and responsive design
- JavaScript: form handling, live preview, content generation and HTML download

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Edit the fields on the left.
4. Select **Generate** to update the preview.
5. Select **AI-style About** to create a sample About Me paragraph.
6. Select **Download HTML** to download the portfolio page.

No installation or internet connection is required for the demo.

## Important AI note
The current project demonstrates an AI-style text generation workflow using a local template. It does not call a real AI model. To make it a real AI-powered application, connect a model API through a backend server, keep the API key on the server, and send only the required user inputs to that backend.
